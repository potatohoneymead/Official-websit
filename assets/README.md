# 美術與多媒體素材資料夾說明

這個資料夾專門用來存放《土豆與蜜酒 | Potato&Honeymead》網頁所需的美術與多媒體素材。

## 目錄結構

```
assets/
├── images/     # 背景圖、店員立繪、菜單餐點圖片、Logo、入口動畫素材等
├── icons/      # 圖標、小按鈕、裝飾用的小符號
└── audio/      # 背景音樂（BGM）、點擊音效、開門環境音等（如有需要）
```

## 素材命名建議（供參考）
- 入口動畫/背景：`entrance-bg.jpg`、`door.png`
- 店鋪 Logo：`logo.png`
- 吧檯背景：`bar-counter-bg.jpg`
- 店員立繪：`staff-01.png`、`staff-02.png`
- 菜單商品圖：`menu-item-01.jpg`
