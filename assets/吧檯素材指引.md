# 吧檯場景素材放置與命名指引

吧檯場景採用嚴格的「前後深度分層架構」，所有素材皆可依據下方表格放置更換：

---

### 1. 吧檯背景影片（放在 `assets/videos/`）

| 項目 | 檔案名稱 | 格式說明 |
| :--- | :--- | :--- |
| **吧檯背景循環短片** | `bar-bg.webm` 或 `bar-bg.mp4` | 滿版覆蓋在最底層，底部已寫好遮罩，往下滑動會平滑漸層融入黑底。 |

---

### 2. 人物動態動畫（放在 `assets/videos/npc/`）

> 💡 **提示**：人物會覆蓋在背景上方、吧檯前台後方。若需要透明背景，建議使用透明 WebM。
> 程式已設定好根據點選不同選項，自動切換對應動作動畫：

| 項目 | 檔案名稱 | 觸發時機 |
| :--- | :--- | :--- |
| **預設待機動作** | `npc-idle.webm` (或 `.mov` / `.mp4`) | 進入吧檯時的自然待機動作。 |
| **說話/引導動作** | `npc-talk.webm` | 點選選項 1 時切換播放。 |
| **微笑/開心動作** | `npc-happy.webm` | 點選選項 2 時切換播放。 |
| **認真/說明動作** | `npc-explain.webm` | 點選選項 3 時切換播放。 |
| *(額外備用動作)* | `npc-action4.webm`、`npc-action5.webm` | 可依需求隨時擴充。 |

---

### 3. 前景吧檯圖片（放在 `assets/images/`）

| 項目 | 檔案名稱 | 格式說明 |
| :--- | :--- | :--- |
| **吧檯前台桌面** | `bar-counter.png` | 透明 PNG，覆蓋在人物前方。底部同樣寫好向下的深色柔和漸層。 |

---

### 4. 左側對話框（NPC 說話圖片，放在 `assets/images/dialogues/npc/`）

| 項目 | 檔案名稱 | 說明 |
| :--- | :--- | :--- |
| **開場打招呼對話** | `dialogue-welcome.png` | 一進吧檯時自動浮現的第一張對話圖。 |
| **點選選項 1 對話** | `dialogue-menu.png` | 客人點擊第 1 個選項後切換顯示的對話圖。 |
| **點選選項 2 對話** | `dialogue-chat.png` | 客人點擊第 2 個選項後切換顯示的對話圖。 |
| **點選選項 3 對話** | `dialogue-about.png` | 客人點擊第 3 個選項後切換顯示的對話圖。 |
| *(其餘擴充對話)* | `dialogue-04.png` ~ `dialogue-07.png` | 支援 6~7 張圖片依序輪播或隨機切換。 |

---

### 5. 右側對話框（玩家可選選項，放在 `assets/images/dialogues/options/`）

| 項目 | 檔案名稱 | 說明 |
| :--- | :--- | :--- |
| **第 1 個選項圖片** | `opt-1.png` | 右側第 1 個按鈕槽位（例如：看看菜單）。帶有 Hover 發光微移動畫。 |
| **第 2 個選項圖片** | `opt-2.png` | 右側第 2 個按鈕槽位（例如：店員閒聊）。 |
| **第 3 個選項圖片** | `opt-3.png` | 右側第 3 個按鈕槽位（例如：酒館故事）。 |
| *(其餘擴充選項)* | `opt-4.png` ~ `opt-5.png` | 備用選項圖，隨時可切換載入。 |
