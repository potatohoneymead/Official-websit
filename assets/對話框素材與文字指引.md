# 吧檯對話框素材放置與文字修改說明

現在對話系統已改為**「一張背景圖 + 純文字」**架構，您只需要準備 2 張底圖，所有文字隨時都可以直接改代碼，大幅減少美術作圖工作量！

---

### 🎨 1. 美術底圖放置指引（只需要這 2 張！）

| 項目 | 檔案名稱 | 放置路徑 | 說明 |
| :--- | :--- | :--- | :--- |
| **左側 NPC 對話框底圖** | `dialogue-box-bg.png` | `assets/images/dialogues/npc/` | 一張對話框外框底圖（建議透明底 PNG，正中間保留空白放文字）。 |
| **右側 選項框底圖** | `options-box-bg.png` | `assets/images/dialogues/options/` | 一張選項面板底圖（建議透明底 PNG，正中間保留空白放 3 行選項）。 |

---

### ✍️ 2. 如何修改文字？

所有文字皆已套用 **思源黑體 TC Regular 400（Noto Sans TC）**，並自動置於圖片正中心。

#### A. 修改「右側 3 行選項文字」
在 `bar.html` 的第 121~129 行：
```html
<button class="dialogue-option-line" data-option="1" id="opt-line-1">
  看看店內推薦菜單
</button>
<button class="dialogue-option-line" data-option="2" id="opt-line-2">
  和店員隨意閒聊
</button>
<button class="dialogue-option-line" data-option="3" id="opt-line-3">
  打聽土豆與蜜酒的故事
</button>
```

#### B. 修改「一進來時的開場白」
在 `bar.html` 的第 112 行：
```html
<div class="dialogue-text-content" id="npc-dialogue-text">
  歡迎光臨土豆與蜜酒！今晚想喝點什麼，還是聽個故事呢？
</div>
```
