# 素材放置與命名清單

已為您建立好專門的資料夾結構。為了讓入口動畫與畫面正常串接，請依照以下路徑與名稱存放檔案：

---

### 1. 影片類素材（放到 `assets/videos/`）

| 項目 | 建議檔案名稱 | 格式說明 |
| :--- | :--- | :--- |
| **1. 背景影片** | `entrance-bg.mp4` / `.webm` | 幾秒短片，會自動靜音、無限循環播放，並支援滑鼠視差微動效果。 |
| **2. 卷軸展開影片** | `scroll-open.webm` / `.mov` | **透明通道動畫**。開啟網頁時自動播放 1 次，播完無縫切換為標準字圖片。 |
| **3. 卷軸收起影片** | `scroll-close.webm` / `.mov` | **透明通道動畫**。點擊 Enter 後先回正標準字，接著播放此收起動畫。 |
| **4. 最頂層過場轉場動畫** | `scene-transition.webm` / `.mp4` / `.mov` | **全螢幕最頂層轉場動畫**。卷軸收起後立刻在所有物件最上層播放，播完後正式進入吧檯。 |

> 💡 **透明影片相容性小提示**：
> - Apple / Safari 原生完美支援帶透明通道（Alpha Channel）的 **`.mov`**（ProRes 4444 或 HEVC with Alpha）。
> - Chrome / Edge / Firefox 等瀏覽器在 Web 端標準支援帶透明通道的 **`.webm`**（VP8/VP9 with Alpha）。
> - 程式碼中已為您同時寫入 `.webm`、`.mov` 與 `.mp4` 備援，您直接放入 `scroll-open.mov` 與 `scroll-close.mov` 即可；如果想讓所有瀏覽器（特別是 Windows 上的 Chrome）都能流暢顯示透明影片，也可以一併放一份同檔名的 `.webm` 檔。

---

### 2. 圖片類素材（放到 `assets/images/`）

| 項目 | 檔案名稱 | 說明 |
| :--- | :--- | :--- |
| **3. 標準字圖片** | `logo-title.png` | 展開影片最後一幀的靜態透明背景圖（PNG）。網頁中已加上緩慢上下漂浮的微動畫效果。 |
| **4. 進入酒館圖片** | `enter-prompt.png` | 寫有 Enter / 進入酒館的透明圖片（PNG）。網頁中會以慢速呼吸頻率閃爍（像按任意鍵效果）。 |

---

### 💡 備註說明
- 若圖片或影片尚未放入，頁面上會保留有質感的預設文字以供測試點擊。
- 素材丟入對應資料夾後，重新整理瀏覽器（F5）即可直接看見效果！
